# 공문 HWPX 템플릿 편집 규약 (사용자 작업 가이드)

`공문 기본 템플릿.hwp`(Downloads)를 아래 규약대로 편집한 뒤 **한컴오피스에서 다른 이름으로 저장 → HWPX 형식**으로 저장해 전달해 주세요. 배치 위치: `frontend/public/hwpx/letter.hwpx`.

시스템은 이 템플릿의 `{{토큰}}`을 실제 값으로 치환하고, `{{BODY}}` 문단 자리에 웹에서 작성한 본문(문단·표·붙임 목록)을 생성해 넣습니다. 상단 로고부·구분선·하단 고정부의 서식은 원본 그대로 보존됩니다.

## 1. 치환 토큰 배치 (일반형 기준)

각 값 위치의 기존 텍스트를 아래 토큰으로 교체합니다. **토큰은 반드시 한 번에 타이핑**하고 중간에 서식(글꼴·크기)을 바꾸지 마세요(내부적으로 텍스트가 쪼개지면 치환에 실패합니다). 라벨(`수    신 :` 등)과 주변 서식은 그대로 둡니다.

| 위치 | 기존 예시 | 토큰 |
|---|---|---|
| 수신란 값 | 삼성전기㈜ 부산사업장 | `{{RECEIVER}}` |
| 참조란 값 | 안전환경팀 변성욱 프로 | `{{REF}}` |
| 제목란 값 | ○○○ 청구 관련 | `{{SUBJECT}}` |
| 본문 전체 | 1. 귀사의 무궁한… (전부 삭제) | `{{BODY}}` 한 문단만 |
| 담당 이름·직급 | 이 재 영 부장 | `{{CONTACT_NAME}} {{CONTACT_POSITION}}` |
| 시행 번호 | 2026-대외-01011 | `{{LETTER_NO}}` |
| 시행 날짜 | (2026. 04. 02.) | `({{ISSUE_DATE}})` |
| 전화/메일 | 02-6672-0035 / kaikan00@naver.com | `{{PHONE}} / {{EMAIL}}` |

- 사명·대표이사 서명줄(`주식회사 한국환경안전연구원 대표이사  이 유 억`)은 **그대로 유지**합니다(치환 안 함).
- `{{BODY}}` 문단과 서명줄 사이의 **빈 문단은 전부 삭제**해 주세요 — 본문 길이에 따른 여백은 시스템이 자동 삽입합니다(A4 1장 맞춤).
- 붙임 목록은 시스템이 본문 뒤에 자동 생성하므로 템플릿에서 **삭제**합니다.
- 내용증명형(발신/수신 풀주소)은 시스템이 수신/참조 라인을 프로그램으로 확장 생성하므로 템플릿은 일반형 1벌이면 됩니다.

## 2. `{{BODY}}` 문단 서식

`{{BODY}}` 문단에 **본문 기본 서식**을 적용해 두세요(시스템이 이 문단의 서식을 추출해 모든 본문 문단에 사용):
- 글꼴·크기: 기존 공문 본문과 동일(휴먼명조 계열 10pt)
- 왼쪽 여백(들여쓰기) 65pt — 기존 본문 문단 서식 그대로면 됩니다

## 3. 서식 참조 카탈로그 (문서 맨 끝에 추가)

시스템이 서식 정보를 추출한 뒤 삭제하는 참조용 요소입니다. 문서 맨 끝에 순서대로 추가:

1. `{{S_BOLD}}` — 한 문단. 텍스트 전체에 **굵게** 적용(본문과 같은 글꼴·크기).
2. **2×2 표** 하나 — 기존 공문의 내역표와 동일한 테두리 스타일로 만들고, 첫 번째 셀에 `{{S_TABLE}}`만 입력. 나머지 셀은 비움.

## 4. 인감 이미지

법인 인감 PNG를 서명줄의 날인 위치(대표이사 성명 위에 겹치게)에 **미리 삽입**해 두세요(글 앞으로/글 뒤로 배치 무관). 웹에서 "인감 날인" 체크를 해제하고 작성한 공문은 시스템이 이 이미지를 제거한 채 생성합니다.

## 5. 저장

- 파일 → 다른 이름으로 저장 → 파일 형식 **HWPX** 선택 → `letter.hwpx`
- 저장 후 전달해 주시면 `frontend/public/hwpx/letter.hwpx`로 배치하고 생성 테스트를 진행합니다.
