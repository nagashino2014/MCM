정식 운영 전에 실제 업무 흐름대로 써 보시고, 불편한 점·오류를 알려 주시는 것이 이번 테스트의 목적입니다.

## 1. 접속과 로그인

- 주소: **https://koensain.app** (PC 브라우저 권장. 크롬·엣지)
- 모바일: 앱 설치 전이라면 홈 화면의 "모바일 앱 데모"로 체험할 수 있습니다.
- 로그인 ID = **사번**, 초기 비밀번호도 **사번**입니다. 첫 로그인 때 비밀번호를 바꾸셔야 다음 화면으로 넘어갑니다.
- 공용 PC에서는 "로그인 유지(30일)"를 켜지 마세요. 로그인 유지를 켜지 않으면 12시간 뒤 자동으로 로그아웃됩니다.
- 사번을 모르거나 로그인이 안 되면 `[담당자 이름·연락처]`로 연락 주세요.

## 2. 이렇게 테스트해 주세요

1. 평소 하던 일을 그대로 해 보세요. 메일, 전자결재(기안·결재), 일정, 할 일, 업무추진계획 보고, 내 휴가·근태 확인, 내 급여명세서 확인 등.
2. 막히거나 이상하면 **그 자리에서** 알려 주세요. 보고할 때 아래 네 가지를 적어 주시면 바로 확인할 수 있습니다.
   - 어느 화면(메뉴 이름 또는 주소창의 주소)
   - 무엇을 하려고 했는지
   - 무엇이 나왔는지(오류 문구가 있으면 그대로, 가능하면 화면 캡처)
   - 시간
3. 보고 방법: `[예: 게시판 "오픈 테스트 피드백" 글 / 메신저 ○○○ 채널 / 메일 ○○○@koensain.com]`
4. 테스트 중 입력한 데이터는 실제 데이터로 남습니다. 연습용으로 넣은 것은 제목에 **[테스트]** 를 붙여 주세요.

- 권한이 없는 메뉴는 보이지 않으며, 주소로 직접 들어가면 "이 화면을 볼 권한이 없습니다" 안내가 뜹니다. 필요한 권한이 있으면 `[담당자]`에게 요청해 주세요.

- 권한이 바뀌면 **다시 로그인**해야 메뉴에 반영됩니다.
- 모바일 앱의 영업·입찰 편집 버튼은 별도 앱 업데이트 전까지 비활성입니다.
