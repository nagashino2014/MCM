## 재발 방지

`infra/aws/ops/assert-deploy-source.ps1`를 배포 스크립트에 연결했다. 미커밋 추적 변경·미추적 웹 빌드 입력·origin/main과 다른 HEAD를 차단한다. 원격 갱신 실패 시 중단하며 `-Force`도 이 검사를 우회하지 못한다. 기존 원격 누락 검사에 codex 브랜치도 포함한다.

배포는 사용자 승인 후 커밋·main 통합·푸시까지 마친 소스로 수행해야 한다. 새 이미지 배포만 하고 Git 통합을 남겨두지 않는다. 별도 롤백이 필요하면 운영 버전과 소스 통합 상태를 함께 확인한다.
