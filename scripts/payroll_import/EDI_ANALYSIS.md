**핵심 규명 — "EDI 고지액 vs 대장 반영액 차이"의 정체**: 차이가 나는 것이 아니라 **항목별로 소스가 다르다**.
국민연금·건강보험(+정산 3종)은 EDI 고지액을 그대로 전기하고, 고용보험·장기요양·지방소득세는 세무사가 산식으로 매월 재계산한다.
고용보험만 고지액과 산정액이 어긋나는데 그 차액을 `정산-고용보험`으로 매월 보정하는 구조다.

## 2. EDI 데이터 취득 경로 조사

- **공식 API 없음.** 4대보험 고지내역은 [건강보험 웹EDI](https://edi.nhis.or.kr)의 "4대보험 사업장 고지(산출)내역서(개인별내역)"에서 확인하며, [엑셀 다운로드를 공식 제공](https://edi.nhis.or.kr/webedi/help/html/receive/re_04.html)한다(개인별 보수월액·산출보험료·정산보험료 포함 — 자동 산출에 필요한 입력이 전부 들어 있음). 로그인은 공동인증서라 서버 자동화 불가.
- **바로빌: 4대보험 관련 API 없음** (2026-08-14 [dev.barobill.co.kr 상품 카테고리](https://dev.barobill.co.kr/services/category) 전수 확인 — 세금계산서·현금영수증·전자문서·문자·팩스·카톡·홈택스 매입매출·사업자상태·카드·계좌조회가 전부).
- CODEF: [건강보험 산출내역 API](https://developer.codef.io/products/public/each/pp/hi-insurance-calculation-details) 등 존재하나 **사용자 방침상 미사용 확정**(2026-08-14).
- 쿠콘 등 타 벤더에 "4대보험 통합조회 EDI" 상품이 있으나, 신규 벤더 계약 대비 실익 낮음.

**권고(확정안): 1차 = 웹EDI 엑셀 수동 다운로드 → 앱 업로드 파서.**
월 1회(고지서 도착 후) 담당자가 개인별내역 엑셀을 받아 앱에 업로드하면, 파서가 직원 매칭 후
국민연금·건강보험 고지액과 정산 3종을 대장에 반영하고 나머지(고용·장기요양·지방세·소득세)는 산식/세액표로 자동 산출한다.
현행 "세무사에게 전달" 단계가 "앱 업로드"로 바뀌는 구조라 업무 변화가 최소다.

## 2-1. EDI 샘플 실측 검증 (2026-08-14, 사용자 제공 2026.05~07 3개월분) ★확정

샘플: `V:\업무자료\경리업무\4대보험\2026\2026년 {5,6,7}월 {건강보험,연금보험} 개인별 고지산출내역(연구원).csv` (cp949, 상단 공백 6행 + 헤더).
고용/산재는 요율 자체 계산이라 EDI 미사용(사용자 확인) — §1의 고용보험 산식 결론과 부합.

**파일 포맷(파서 스펙 확정):**
- 건강보험: `순번,증번호,주민번호,성명,보수월액,[구분,산출보험료,정산보험료,정산사유,정산적용기간,감면사유,연말정산,환급금이자,고지보험료,회계,영업소기호,직종,취득일/상실일]×2세트(건강=idx5~17, 요양=idx18~30)`
- 연금보험: `순번,국민연금번호,주민번호,가입자명,정산사유,정산적용기간,결정보험료`

**대장 실측 대조 결과(2026.05~07):**
| 매핑 | 일치율 |
|---|---|
| 대장 `건강보험` = 건보 **산출보험료**(idx6) | **93/93 (100%)** |
| 대장 `장기요양보험료` = 요양 **산출보험료**(idx19) | **93/93 (100%)** |
| 대장 `정산-건강보험` = 건보 **정산보험료**(idx7) | 26/27 (1건 차이 — 수기 보정 추정, 업로드 시 경고 표시) |
| 대장 `국민연금` = 연금 **결정보험료 ÷ 2**(총액 9% 중 근로자 4.5%) | **84/84 (100%)** |
| 귀속월 | EDI n월 고지 = **n월분 대장에 그대로 반영**(시프트 없음) |

→ 업로드 파서는 성명(+주민번호 앞자리) 매칭으로 위 4개 항목을 자동 기입하면 되고, 세무사 산출과 완전 동치임이 실증됐다.

## 3. P4 본 구현 반영 사항

1. **EDI 업로드 파서 + 고지액 저장 테이블**(`payroll_edi_notices`): 귀속 연월×직원×보험별 고지액·정산액. 엑셀 포맷은 샘플 확보 후 확정.
2. **간이세액표 시딩 테이블**(`income_tax_brackets`, 연도 버전): 국세청 고시 간이세액표(월급여 구간×부양가족수). 직원별 부양가족수 컬럼(+80/100/120% 선택 비율) 필요.
3. **산식 자동 항목**: 고용보험(과세급여×요율표), 장기요양(건보×요율표), 지방소득세(소득세×10% 10원 절사) — 연도별 요율 테이블 시딩.
4. **규칙 등록형**: 학자금상환공제(월 정액·기간·잔액 추적) — §6-2 A 수당 규칙 테이블과 통합.
5. 검증 게이트: 생성된 대장의 공제 합계를 과거 동월 실측과 대조하는 검증 뷰.
