# 모바일 앱 기능 갭 분석 — 데스크탑 전 메뉴 대비 (2026-08-06)

데스크탑 웹앱(`frontend/`)에 구현된 **전 메뉴·기능**과 모바일 앱(`apps/mobile/`)의 현재 구현을 하나씩 대조해, 모바일에 **추가할 메뉴·기능**을 우선순위와 함께 정리한다.

판정 기준은 "데스크탑에 있으니 옮긴다"가 아니라 **모바일에서 실제로 값이 나오는가**다. 구체적으로:
- **이동 중·현장에서 발생하는 일인가** (외근 직전 차량 예약, 현장에서 계약 조건 확인)
- **응답 지연 비용이 큰가** (결재 대기, 재보고 요청, 마감 임박)
- **입력 부담이 작은가** (버튼 몇 개 vs 표·리치에디터·다중 첨부)
- **화면이 표/대시보드 중심은 아닌가** (넓은 표는 모바일에서 열화됨)

## 3. 갭 상세 — 데스크탑 메뉴별

### 3.1 협업

#### 메일 🟡
- **데스크탑**: 3-pane, 폴더 관리, 검색, 읽음/안읽음·이동·삭제, 리치 에디터, 다중 첨부, 회사 도메인 계정
- **모바일**: 폴더 전환 · 목록(무한 스크롤) · 상세 · 첨부 다운로드 · 작성/발송 · 답장(인용)
- **빠진 것**: **검색**, 읽음 표시 토글, 폴더 이동·삭제, **첨부 붙이기**(발송 시), 참조/숨은참조 UI, 서명

#### 전자결재 🟡 ★ 가장 큰 갭
- **데스크탑**: 기안(양식 빌더 기반 전 양식) · 결재/반려/대결 · 문서함 · 양식별 조회 · 공문 작성 · 견적서 작성 · 데이터 분석 · 결재 인사이트 · 선행-후행 문서 연관 · 첨부
- **모바일**: 대기/예정/내 기안 **조회** + 상세에서 **승인/반려**, 기안은 **휴가 신청 폼 하나뿐**
- **빠진 것**:
  - **일반 양식 기안** — 지출결의·출장신청·품의 등 자주 쓰는 양식을 모바일에서 올릴 수 없다
  - 문서 **검색**·양식별 조회·문서함(완료/반려 아카이브 필터)
  - **의견 첨부**(반려 사유 외 코멘트), 결재선 변경, 대결·위임
  - 공문/견적서는 작성 자체가 무거워 **조회만** 필요
  - 첨부파일 **추가**(촬영·파일 선택)

#### 일정(캘린더) 🟡
- **데스크탑**: 그룹웨어 일정(본인·부서·차량·선택 일정 필터), 일정 등록/수정, 출장·교육·휴가 자동 반영, 공휴일
- **모바일**: 영업 활동 + 휴가만 표시. **일정 등록 불가**, 차량·회의·교육 일정 없음
- **빠진 것**: 그룹웨어 일정 전체 통합(`/api/home/calendar` 의 scope 확장), **간단 일정 등록**, 참조 대상 선택

#### 자산 예약(차량) ❌ ★ 모바일 적합도 최상
- **데스크탑**: 차량 등 자산 이용 현황(캘린더/타임라인), 예약 생성·취소, 자산 관리(문서·계약서 PDF)
- **모바일**: 없음
- **왜 모바일인가**: 외근 직전 주차장에서 "지금 차 되나?" → 예약이 전형적인 이동 중 행위다. 입력도 가볍다(자산·시각·목적지)
- **필요 화면**: 오늘/이번 주 이용 현황 → 빈 시간대 탭 → 예약, 내 예약 취소

### 3.2 업무

#### 업무추진계획 ❌
- **데스크탑**: 주간 보고 작성/제출, 부서장 감독, 임원 검토·지시, 발표 모드, 병합
- **모바일**: 홈 위젯이 "할 일 N건"만 알림, 실제 작성·응답 불가
- **필요 최소선**: 내 보고 **조회**, **재보고 요청 확인 → 코멘트 응답**, 간단 진행률 입력. 전체 작성/발표 모드는 데스크탑 유지

#### 사업참여 수행인력 ❌
- **데스크탑**: 수행인력 현황, 반기 참여도·평점
- **모바일**: 없음. **내 참여 이력·내 평점 조회**만 있으면 충분(관리 기능은 데스크탑)

#### 근태·휴가 🟡
- **모바일 있음**: 내 휴가(잔여·이력)·휴가 신청·내 근태(주별)
- **빠진 것**:
  - **초과근무 12h 초과 동의**(전자서명) — 현재 웹 전용. 근태 파이프라인상 즉시 응답이 필요한 항목
  - **연차 사용 촉진 고지 회신**(1·2차) — 홈 위젯이 `/leave` 로 보내지만 회신 UI 자체가 모바일에 없음
  - 휴가 **취소/변경** 신청
  - 관리자용(직원별 휴가·근태 관리, 휴가 종류 규정)은 데스크탑 유지

### 3.3 사업 운영

#### 사업장 🟡
- **데스크탑**: 검색·목록 + `FacilityDetailPanel`(일반현황·허가·담당자·계약·활동·문서, 4천 줄)
- **모바일**: 검색·목록만. **상세가 없다**
- **필요**: 요약 상세(기본정보 · 담당자 연락처 · 진행 계약 · 최근 활동 · 지도앱 연결) — `/m` 프로토타입에서 이미 설계된 "요약 카드" 수준

#### 계약 ❌
- **데스크탑**: 계약 관리(목록·상세·대금단위·수행인력), Dashboard, 수주/수금/발행 현황, 다운로드/증명서
- **모바일**: 없음
- **왜 모바일인가**: 현장·미팅에서 "이 사업장 계약 범위·기성 단계·미수금"을 확인하는 일이 잦다. 조회는 가볍다
- **필요 최소선**: 내 계약/사업장 계약 **조회**(기간·금액·단계·수금 상태), **세금계산서 발행 요청**(홈 위젯에 이미 있는 흐름의 실행 화면). 대시보드 차트·증명서 생성은 데스크탑

#### 영업/마케팅 🟡
- **모바일 있음**: 담당자 검색, 공공입찰 매칭, 일정 화면의 활동·경과 입력
- **빠진 것**:
  - **Salesboard**(영업건 파이프라인·단계) 조회 — 현재 활동 단위로만 보임
  - **활동 신규 등록**(일정 추가) — 경과 입력만 가능
  - 입찰 **증빙서류 패키지 진행 상황** 조회
  - intel(DART 신호·발주 소스)·RAG 발굴은 분석 화면이라 **모바일 제외** 권장

#### 데이터(수집 현황·검수·설정) ❌
- 대량 표·검수 작업 → **모바일 제외**

### 3.4 관리
사용자 관리 · 회사 프로필 · 결재 운영 설정(양식 빌더·의미 사전·관계 맵·지표·정책) · 휴지통 → 전부 **모바일 제외**. 운영자가 앉아서 하는 일이고 입력이 무겁다.

### 3.5 모바일에만 있는 것 (역방향)
명함 촬영(AI 인식) · 앱 잠금(생체) · 푸시 알림 설정 · 날씨/시계 위젯. 유지·강화 대상.

## 6. 제안 로드맵

- **1차(P0)**: 차량 예약 · 일정 통합/등록 · 일반 양식 기안 · 근태/휴가 응답 액션
  → 탭 IA 변경 없이 더보기·홈 빠른실행에 진입점 추가. 신규 백엔드 거의 없음
- **2차(P1)**: 사업장 상세 · 계약 조회 · 발행 요청 · 업무추진계획 응답 · 메일/결재 보강
  → 사업 운영 도메인을 모바일에 처음 여는 단계. 상세 화면 설계 필요
- **3차(P2)**: 영업 등록·조회 확장, 촬영 첨부
- **별도**: 메신저(대화 탭)

착수 전 확인이 필요한 것:
1. 차량 예약의 실제 사용 빈도와 승인 절차 유무(예약 즉시 확정인지)
2. 모바일에서 올릴 양식 우선순위(지출결의·출장신청 등 실제 빈도)
3. 계약 조회의 권한 범위(본인 참여 계약만 vs 전사)
