> v1 초안에 대한 사용자 1차 검토(2026-08-05)를 반영한 판. 구현 계획 확정 전 단계.

## 확정 사항 (2026-08-05 사용자 지시)

1. **xlsx 생성 = exceljs 신규 도입** (§5-3 B안 확정).
2. **발송 포맷 = PDF만** — 임의 사용·변조 위험 차단. xlsx는 내부 보관·다운로드용.
3. **공문 연계 기능 배제** — 견적서를 공문과 함께 보내는 경우가 거의 없음. 갑지는 견적서
   파일 내 시트로만 존재.
4. **견적 번호는 포맷 채번** 도입(§5-4). 과거 견적서 **대장 마이그레이션(백필)은 하지 않음**
   — 체계적 번호 정리가 안 되어 있고 누락·소재 불명 다수. 단, 과거 견적서는 **캘리브레이션
   자료로는 추가 제공** 예정(Q0에서 활용).
5. **VAT 별도·유효기간(견적일로부터 1개월)은 고정** 구현.
6. **작성 권한**: 각 본부별 부서장 + 총괄 + 대표이사 + **영업관리본부 전체**.
7. **발송 여부를 작성 시 선택** — 발주처 담당자 메일 발송 외에, 발주처 전자조달시스템에
   업로드하는 케이스가 많음. 발송 체크 해제 시 결재 승인 후 산출물(PDF)만 생성·보관하고,
   사용자가 다운로드해 직접 조달시스템에 첨부(§5-4).
8. **요율은 표준요율을 기본값으로 두되 건별 탄력 조정** — 표준요율(제경비 110%, 기술료 20%)
   을 소액 용역(변경허가/신고 등)에 그대로 적용하면 MD 과소 계상을 요율로 보정해온 실무가
   있고, 극심한 통합인허가 불경기에서는 "낙찰될 만한 가격"이 우선이라 표준요율의 의미가
   퇴색함. → 요율 자유 조정 + **상황 변수 레이어**(§5-1-b) 신설.
9. **(2차 검토) MD는 견적가 역산 방식** — 제출 견적가를 입력하면 업무단위별 기본 MD
   가중치로 세부 MD를 자동 분배(§5-1-c). 1천만원 미만 소규모 용역이 아닌 한 **MD는 0.5
   단위로 떨어지게 자동 스냅**.
10. **(2차 검토) 산출 합계는 견적가보다 무조건 크게 + 초과폭 상한** — 직접인건비+제경비+
    기술료(+직접경비) 합계가 견적가를 반드시 상회하되, 초과폭은 견적가 구간별 상한 미만:
    ~5백만 10만 / 5백~1천만 20만 / 1천만~5천만 30만 / 5천만~1억 50만 / 1억~2억 100만 /
    2억~ 200만. MD 산정으로 견적가가 정확히 떨어지는 부자연스러움을 피하고 "약간의 네고"를
    어필하기 위함.
11. **(2차 검토) 견적번호 = `{연도}-{용역 종류}-{NNNN}`** (예: `2026-통합허가-0001`).
    용역 종류 5종: 통합허가 / 화관법 / HAPs / ESG / 기타 — 종류별 독립 시퀀스.
12. **(2차 검토)** 캘리브레이션 자료는 구현 중 필요 시 사용자에게 요청(사용자가 찾아 제공).
    상황 변수 사유 코드 초기 6종 승인.

## 1. 배경 / 문제

- 견적서는 현재 엑셀 수작업으로 작성·발송된다. 갑지/견적서/별첨(MD 산정·단가표) 구조는 정형화되어
  있으나, **견적가와 MD 산정에 명확한 기준이 없어** 작성자의 자의적 판단, 기존 견적서 참조,
  막연한 추세 예측에 의존해 왔다.
- 실물 견적서 4종 실측 결과(§3), 같은 회사 양식인데도 제경비율 70~110%, 기술료율 10~20%로
  건마다 요율이 다르고, MD 산정 근거가 문서마다 상이하다.
- 환경부 「통합허가 대행비용 산정 가이드라인」(§4)이 존재하나, 이 기준대로 산출하면 실제 용역
  낙찰가 대비 매우 높은 금액이 나온다 → **그대로 적용 불가, 구조(인자×단위MD×조정계수)만 차용**.

## 2. 목표

1. **견적 산정 엔진**: 용역 세분류별 × 업종별 × 규모별(배출시설 개수 구간)로 정교하게 세팅
   가능한 견적가·MD 산정 기준을 DB화하고, 산정 인자를 입력하면 MD와 견적가(표준가)가 자동
   산출된다. 그 위에 **상황 조정 레이어**(요율 탄력 조정 + 상황 변수: 발주처 네고·경쟁 격화
   등)를 두어 "낙찰될 만한 제출가"를 유연하게 만들되 조정 근거는 데이터로 남긴다.
2. **세분류 전면 대응**: 계약관리의 용역 세분류 전체(통합허가 7종·장외&화관법 10종·HAPs 8종·
   ESG탄소중립 7종·기타 6종)에 대해 견적서를 작성할 수 있다(§5-2 3티어 전략).
3. **문서 생성**: 현행 회사 양식 그대로(갑지 + [총괄] + 사업장별 견적서 + 별첨1·2) xlsx·PDF를
   자동 생성한다. 총괄 시트는 **허가 대상 사업장 4개 이상**일 때 자동 삽입.
4. **결재·발송**: 공문과 동일하게 전자결재 위임 → 최종 승인 시 수신처 메일 자동 발송,
   발송 대장 관리. 공문 파이프라인(채번·PDF·메일·대장) 최대 재사용(§9).
5. **피드백 루프**: 수주/낙찰 결과를 견적 이력에 연결해 기준 세트를 지속 보정할 수 있는
   토대(시장 보정계수)를 만든다.

### 3-1. 공통 구조

- **갑지**: 회사 주소/연락처 상단 + 일자·수신·용역명 + "견적서를 첨부와 같이 제출합니다" +
  첨부 목록(부수 표기) + 회사명·대표이사 서명. 공문 표지와 유사한 성격.
- **견적서 시트**: ①공급자 블록(상호·등록번호 557-86-00306·대표이사·담당자·연락처 — 고정정보)
  ②건명 ③견적 조건(결재조건/납품기한/납품장소/유효기간 "견적일로부터 1개월")
  ④견적금액 — **한글 금액 표기**("一金 이억 원정") + 숫자 + (V.A.T별도)
  ⑤품목표: 직접인건비 / 제경비(=직접인건비×요율) / 기술료(=(직접인건비+제경비)×요율)
  [+ 직접경비(상주 시)] ⑥합계 → ⑦**최종 견적 금액**(십만 단위 이하 절삭 또는 네고 금액)
  ⑧특이사항(용역 범위·자료 제공 조건·대금지불조건 등 자유 문장).
- **별첨 1 (MD 산정 내역)**: 업무 항목 트리(대항목 → 세부항목, 통합계획서 1~8장 등) ×
  인력 등급 4단계(기술사 or 특급 / 고급 / 중급 / 초급)별 MD → 등급별 소계 × 노임단가 =
  직접인건비. **업무 항목 트리는 세분류마다 다르다**:
  - 최초허가: 환경진단 → 현장조사 → 도면·물질수지 → 계획서 작성(1~8장) → 협의/허가 대응 → 사후관리 구축
  - 변경허가: 기존 계획서·변경사항 검토 → 변경 계획서 작성(1~8장) → 변경허가/신고 대응
  - 재검토: 기존 서류 검토·현장 확인 → 재검토 계획서 작성(1~8장) → 재검토 대응
- **별첨 2 (단가 기준표)**: 엔지니어링 기술자 노임단가(환경분야, 연도별 개정 — '22년 기술사
  379,482원 → '26년 456,237원) + 제경비·기술료(+직접경비) 적용 요율과 근거 고시 표기.

## 4. 환경부 「통합허가 대행비용 산정 가이드라인」 요약 (참고자료)

> 출처: 환경부 발행 PDF 확보 완료(8p). **구조만 차용하고 절대액은 그대로 쓰지 않는다** —
> 이 기준의 산출액은 실제 낙찰가보다 매우 높다(§2 참고).

- **방식**: 엔지니어링산업진흥법 §31②의 실비정액가산방식.
  대행비 = 직접인건비(조정계수 반영) + 직접경비(타 항목 합계의 10~15%) +
  제경비(직접인건비의 110~120%) + 기술료((직접인건비+제경비)의 20~40%) → 할인·할증 → 입찰가 적용율.
- **업무량 산정 인자 5종**(단위당 등급별 소요일수 표 존재):

| 인자 | 합계 MD/단위 | 특급 | 고급 | 중급 | 초급 |
|---|---|---|---|---|---|
| 단위공정 수 | 2.5 | 0.5125 | 0.2375 | 0.4625 | 1.1500 |
| 취급물질 수 | 0.6 | 0.1000 | 0.1000 | 0.2250 | 0.2625 |
| 배출·방류구 수 | 3.7 | 0.5125 | 0.6875 | 1.0875 | 1.4375 |
| 대기배출시설 수 | 1.9 | 0.4000 | 0.2125 | 0.3625 | 1.0000 |
| 사업장(고정) | 17.2 | 2.1875 | 3.1000 | 4.9250 | 6.9625 |

- **조정계수**(규모별 편차 완화 — "배출시설 수가 대행비용의 핵심 인자"):
  - 배출시설: 1~50개 사업장 **2.0** / 50개 이상 `y = 75/x + 0.5`(5,000개까지) /
    5,000개 초과분 `y' = 75/x' + 0.25` (준중형 150개 = 1.0 기준)
  - 취급물질: 연간 1톤 이상 1.0 / 1톤 미만 0.5
- **규모 분류**: 초소형(배출시설 30 미만, LNG발전·소각) ~ 초초대형(10,000 이상, 정유·화학 병행).
- **할인·할증**: HAPs·VOC 허가 포함 시 각 +7.5%(최대 +15%) / 연소시설·폐수처리장 없으면
  각 -7.5%(최대 -15%).
- **입찰가 적용율**: 업체 자율(예시 0.85~0.90).

→ **차용할 것**: 인자×등급별 단위MD 산식 구조, 배출시설 개수 기반 규모 조정계수 개념,
할인·할증(가·감액 요인) 개념. **버릴 것**: 절대 MD 값(자사 실적 기반으로 재캘리브레이션),
연속함수형 조정계수(운영자가 이해·조정하기 어려움 → 구간표로 대체).

## 5. 핵심 설계

### 5-1. 견적 산정 엔진 — "견적 기준 세트"의 DB화 + 상황 변수 레이어

산정은 두 층으로 분리한다. **(a) 표준가 산정**(세분류×업종×규모 기준 세트 — 재현 가능하고
안정적인 내부 기준)과 **(b) 상황 조정**(시장·경쟁·네고 등 그때그때의 판단 — 자유 조정이되
사유가 기록으로 남는 층). 표준가는 흔들리지 않게, 제출가는 유연하게.

#### (a) 표준가 산정 — 견적 기준 세트

하드코딩이 아니라 **관리자가 화면에서 편집하는 기준 데이터**로 만든다. 세분류별 기준 세트는
버전 관리되어, 견적서에는 산정 당시 세트 스냅샷이 박제된다(사후 기준 변경이 기존 견적을
훼손하지 않음 — 공문 fit_params 스냅샷과 같은 철학).

```
견적 기준 세트 (quote_rate_sets: 세분류별 1개 활성 버전)
├─ ① 산정 인자 정의 (factors)        — 세분류마다 자유 정의
│    통합허가: 배출시설수, 배출구·방류구수, 단위공정수, 취급물질수
│    화관법:   유해화학물질 취급시설수, 취급물질수, 시설 규모 등
│    (인자 없음도 허용 → 티어2·3, §5-2)
├─ ② 업무 항목 트리 (work items)     — 별첨1의 행이 됨. 항목별·등급별 MD 산식:
│    MD(항목, 등급) = 기본MD + Σ_인자( 인자값 × 단위MD(항목, 등급, 인자) × 규모계수 )
├─ ③ 규모 구간표 (size bands)        — 기준 인자(통합허가=배출시설수)의 구간별 계수
│    예: ~30(소) 1.6 / 31~150(중) 1.0 / 151~600(대) 0.75 / 601~(초대) 0.55  ← 초기값은 캘리브레이션으로 결정
├─ ④ 업종 계수 (industry coefs)      — 통합허가 대상 20개 업종(lib/ieps/integrated-permit-industries.ts
│    태그 재사용) + 화관법 업종. 기본 1.0, 복잡 업종(화학·제철 등) 상향
├─ ⑤ 요율 기본값                     — 제경비율·기술료율·직접경비율(상주 시)·라운딩 규칙
├─ ⑥ 할증·할인 항목                  — HAPs/VOC 포함 +α, 연소시설·폐수처리장 無 -α, 상주 조건 등 (체크박스식)
└─ ⑦ 시장 보정계수                   — 환경부식 산출액 → 자사 수주가 현실화 계수 (세트 전체에 1개)
```

- **노임단가 테이블**(quote_labor_rates): 연도별 × 등급별(기술사/특급/고급/중급/초급)
  엔지니어링 환경분야 노임단가. 별첨2와 산정의 공용 원천. 매년 1행 추가만 하면 됨.
- **초기 캘리브레이션**: 실물 견적 4종 + **사용자 추가 제공 예정분**을 기준 세트에 역대입해
  단위MD·규모계수 초기값을 산출한다. 예: 케이지스틸(변경허가·소규모) 15MD ↔ 삼양사(재검토·
  중규모) 73MD ↔ 샘플(최초·중규모) 350MD ↔ 포스코퓨처엠(최초·대규모) 1,016MD가 재현되도록
  맞춘다. → 구현 단계에서 "기준 세트 시드 SQL"로 제공하고, 이후 관리자 화면에서 조정.
  (과거 견적서는 캘리브레이션 자료로만 쓰고 대장 백필은 하지 않음 — 확정 사항 4)

#### (b) 상황 조정 레이어 — 제출가는 유연하게, 근거는 기록으로

표준가 산정 후, 건별로 다음을 자유 조정해 **제출가**를 만든다. 모든 조정은 스냅샷에 남아
"어떤 상황에서 얼마를 깎았는지"가 데이터가 된다(수주 결과와 결합해 §5-5 피드백 루프의 원료).

| 조정 수단 | 내용 |
|---|---|
| 요율 조정 | 제경비율·기술료율·직접경비율을 표준요율 기본값에서 건별 자유 변경(실물 70~110% 실측 그대로) |
| MD 셀 조정 | 자동 산출 MD를 셀 단위 수동 오버라이드(조정 흔적 표시) |
| **상황 변수** | 사유 코드 선택 + 조정률/조정액 + 메모. 사유 코드(초기): `발주처 네고 요구` / `경쟁 격화(경쟁사 저가)` / `전략적 수주(레퍼런스 확보)` / `장기 고객 관계` / `긴급 일정 할증` / `기타`. 문서 레벨 또는 사업장 레벨 적용 |
| 최종 금액 확정 | 라운딩 규칙(십만 단위 이하 절삭) 적용 또는 네고 금액 직접 입력("최종 네고 금액" 라벨 자동 전환) |

- 화면에는 **표준가 → 조정 내역 → 제출가**가 나란히 보이는 요약 카드를 둔다(할인율 % 자동
  표시). 견적서 문서에는 제출가만 나가고, 표준가·조정 내역은 내부 데이터로만 남는다.

#### (c) MD 역산 엔진 — 견적가를 입력하면 별첨1이 만들어진다 (2차 검토 확정)

실무의 최종 단계는 정방향(MD→금액)이 아니라 **역방향**이다: 제출 견적가를 확정하면, 그
금액을 뒷받침하는 세부 업무단위별 MD 내역(별첨1)을 자동 생성한다.

```
입력: 제출 견적가 P, 요율(제경비율 o·기술료율 t·직접경비율 d), 기준 세트의 업무항목×등급 MD 가중치 w
① 목표 합계 구간 결정: S ∈ (P, P + cap(P))  — cap은 견적가 구간별 초과폭 상한(아래 표)
② 필요 직접인건비 역산: L ≈ S / ((1+o)(1+t) + d)   — 요율 체인 역산
③ MD 분배: 각 업무항목×등급 셀 MD = L × w(셀) / 노임단가(등급)  — 기준 세트 가중치 비율대로
④ 스냅: P ≥ 1천만원이면 전 셀 0.5 단위 반올림, 1천만원 미만 소규모는 세밀 단위(0.1) 허용
   ※ 소규모 완화 이유: 상한 10만~20만 구간은 0.5MD(초급 기준 약 12만원)보다 좁아
     0.5 스냅으로는 목표 구간 진입이 수학적으로 불가
⑤ 잔차 조정: 스냅 후 합계를 재계산해 S가 목표 구간에 들어올 때까지 조정용 셀(중·초급
   위주)을 스냅 단위로 ±하는 그리디 보정 → 그래도 안 맞으면 마지막 1개 셀만 세밀 단위 허용
출력: 별첨1 MD 표 + 합계(= 견적서의 '합 계 금 액') + 최종 견적 금액(= P, "네고/절삭" 표기)
```

| 견적가 구간 | 합계-견적가 초과폭 상한 |
|---|---|
| ~5백만 | 10만원 미만 |
| 5백만~1천만 | 20만원 미만 |
| 1천만~5천만 | 30만원 미만 |
| 5천만~1억 | 50만원 미만 |
| 1억~2억 | 100만원 미만 |
| 2억~ | 200만원 미만 |

- 초과폭은 항상 **양수**(합계 > 견적가 강제) — "MD로 산정하니 이 금액이 나왔고, 견적가는
  거기서 약간 네고한 금액"이라는 서사가 문서에서 자연스럽게 성립한다(실측 4종 모두 이 패턴).
- (a) 정방향 산정은 **견적가 결정을 돕는 가이드**(표준가 제시)로, (c) 역산은 **문서 확정**
  으로 역할이 정리된다. 담당자는 표준가를 참고해 제출가를 정하고, 시스템이 별첨1을 맞춘다.
- 역산 후에도 MD 셀 수동 조정은 가능하되, 조정 시 합계-견적가 제약을 실시간 검증(위반 시
  경고 배지 + 상신 차단).

### 5-2. 세분류 전면 대응 — 3티어 전략

모든 세분류(계약관리 `CONTRACT_SERVICE_OPTIONS` 기준 38종)에 동일한 정밀 MD 기준을 당장
만들 수는 없다. 티어를 나눠 **전 세분류가 즉시 작성 가능**하되, 기준은 점진 고도화한다.

| 티어 | 산정 방식 | 대상(초기) | 별첨1 |
|---|---|---|---|
| **T1 정밀 산정형** | 인자 입력 → MD 자동 산출(§5-1 풀 엔진) | 통합허가: 최초허가·변경허가·재검토 (실물 견적 보유) | 자동 생성 |
| **T2 항목 단가형** | 업무 항목 트리 + 항목별 고정 MD(인자 없음), 담당자가 MD 직접 조정 | 통합허가 나머지(변경신고·사후관리·통합교육·영업허가), 장외&화관법·HAPs 주요 세분류 | 자동 생성(항목·MD는 수동 조정) |
| **T3 자유 입력형** | 품목·금액 직접 입력(별첨 생략 가능) | ESG탄소중립·기타 등 MD 개념이 약한 용역 | 선택(없으면 견적서 품목표만) |

- 기준 세트가 없는 세분류를 선택하면 자동으로 T3로 동작 → **어떤 세분류도 막히지 않는다**.
- 관리자가 기준 세트를 등록하는 순간 그 세분류는 T2/T1로 승격. 티어는 세트의 속성일 뿐
  코드 분기가 아니다(인자 있음=T1, 항목만=T2, 세트 없음=T3).

### 5-5. 영업·계약 연동

- 견적서에 `facility_id`(수신처·사업장별 라인 모두)와 영업 프로젝트(`sales` P1P2) 연결 필드.

  재조정의 근거(후속 단계, 이번 범위에서는 결과 필드와 링크만).

```sql
           xlsx_key, pdf_key, attach_keys jsonb,
           send_mode(mail|direct),      -- 작성 시 선택: 메일 발송 / 직접 제출(다운로드)
           situation jsonb,             -- 상황 변수: [{code, rate|amount, scope(doc|site_seq), memo}]
           send_status,                 -- pending|generating|generated|sending|sent|failed
           send_error, send_attempts, sent_at, sent_message_id,
           sales_project_id, result(pending|won|lost|dropped), result_note, created_at)
           -- VAT 별도·유효기간 1개월은 고정 정책이라 컬럼 없음(valid_until은 계산값 보관)

-- 사업장별 라인 (산정 스냅샷 포함)
quotation_sites(quote_id FK, site_seq, facility_id, site_label,
                factors jsonb,           -- 입력된 인자값 {배출시설수:150,...}
                md_matrix jsonb,         -- 항목×등급 MD (자동산출+수동조정 최종본, 오버라이드 플래그 포함)
                rates jsonb,             -- 적용 요율·계수 (기준 세트 스냅샷 set_id/version 포함)
                amounts jsonb,           -- 표준가/조정내역/제출가: 직접인건비·제경비·기술료·직접경비·합계·최종금액
                remarks text, PRIMARY KEY(quote_id, site_seq))

-- 채번·양식 시드 (용역 종류별 5개 시퀀스)
doc_no_sequences('견적:통합허가'|'견적:화관법'|'견적:HAPs'|'견적:ESG'|'견적:기타', '2026', 0)
approval_forms('frm-quotation', doc_no_rule='견적', org_folder='견적 문서') + form_versions v1
-- doc_no_rule '견적'은 상신 시 문서의 service_type에 따라 5개 시퀀스 중 하나로 분기
```

문서 원본 = `approval_docs.field_values`(공문과 동일 원칙). `quotations`/`quotation_sites`는
발송·산정 스냅샷 대장. 산정의 재현성은 `quotation_sites.rates`에 세트 버전을 박제해 보장.
