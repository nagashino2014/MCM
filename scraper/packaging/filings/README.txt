MCM 신고 보조 — 설치 안내
==========================

통합환경허가시스템(IEPS) 대행 실적 보고·기술인력 변경신고를 MCM 대외 신고 대기열 값으로
반자동 입력하는 도구입니다. 제출 버튼은 사람이 누릅니다.

[설치]
1. 이 압축 파일을 아무 폴더에나 풉니다.
2. install.cmd 를 더블클릭합니다. (관리자 권한 필요 없음)
   - Windows 가 "PC 보호" 경고를 띄우면 [추가 정보] → [실행] 을 누르세요.
3. Google Chrome 이 설치되어 있어야 합니다.

[사용]
- MCM 앱 > 계약 > 대외 신고 대기열 에서 신고 건의 [신고 보조 열기] 를 누릅니다.
  (브라우저가 "MCM 신고 보조를 열까요?" 라고 물으면 [열기])
- 처음 한 번은 콘솔 창에서 MCM 계정(사번·비밀번호)을 묻고, IEPS 로그인 창(문자인증)이 뜹니다.
  IEPS 에 로그인한 뒤 그 창을 닫으면 신고 화면이 열립니다.
- IEPS 로그인은 약 1시간 유지됩니다. 만료되면 [신고 보조 열기] 가 자동으로 로그인 창부터 띄웁니다.
- 시작 메뉴 "MCM 신고 보조" 에 바로가기가 있습니다.

[신고 순서 — 패널 상단에도 표시]
사업장 검색 → 자동 채우기 → 저장 → 직인·서류 첨부 → 제출
제출하면 MCM 에 제출 완료가 자동 기록되고, 실적 보고서 PDF 를 받아 계약 상세에 붙인 뒤
용역 실무자에게 발송합니다.

[업데이트]
새 설치 파일의 install.cmd 를 다시 실행하면 됩니다. 로그인 정보는 유지됩니다.

[제거]
시작 메뉴 "MCM 신고 보조 > 신고 보조 제거" 또는 설치 폴더의 uninstall.cmd.
로그인 정보까지 지우려면 명령 창에서: uninstall.cmd -RemoveData

[보관 위치]
- 프로그램: %LOCALAPPDATA%\Programs\MCM Filings
- 데이터(IEPS 로그인·MCM 토큰): %LOCALAPPDATA%\MCM\filings  — 다른 사람과 공유하지 마세요.
