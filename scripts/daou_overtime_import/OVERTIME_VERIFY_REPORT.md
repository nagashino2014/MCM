# 초과근무수당 산정 검증 리포트 (2026년 5월분)

> 목적: 급여대장의 초과근무수당을 **신청 기록 × 근태 기록 대조**로 산정하도록 하고,
> 세무사가 작성한 실측 대장과 대조해 산식을 확정한다.
> 데이터: 다우오피스 초과/휴일근무신청 → MCM 전자결재(`frm-overtime-request`) 마이그레이션분.

## 1. 마이그레이션

- 원본: `data/daou/docs/<id>/detail.json`(다우 반출본)의 본문 HTML 표.
- 대상: 신청일 2026-04-26 ~ 05-27 중 **근무일이 2026-04-26 ~ 05-25**(급여 귀속 구간)인 건.
  신청일을 27일까지 넓힌 이유 = 25일 근무를 27일에 사후 신청한 사례 포함(앱 전환 후에는 사후 신청 불허 예정).
- 결과: 신청 66건 중 **58건 적재**(전원 매칭, 스킵 0·승인자 매칭 실패 0), 15명 · 신청시간 합계 196h.
- 스크립트: `parse_overtime.py`(파싱·dry-run) → `import_overtime.py --apply`(적재, 멱등 `doc_id=ovt-daou-<다우문서ID>`).

## 2. 실측 대조로 확정한 산식

| 항목 | 확정 내용 | 근거 |
|---|---|---|
| 기준 시간 | **승인된 초과근무 신청서의 신청 시간** | 5월 근태(ADT) 미적재 구간인데도 실측 대장에 수당이 있었고, 신청시간과 정확히 대응 |
| 가산율 | 주간 1.5배 / **22:00~06:00 야간 2.0배** | 정해원 실측 427,200원 = 시급 17,800 × (14h×1.5 + 1.5h×2.0) — 야간 미적용 시 불일치 |
| 통상시급 | 통상임금 월액 ÷ 209 후 **100원 단위 반올림** | 실측 역산 시급이 전부 100원 단위(19,200·15,200·18,000·24,900 …) |
| 귀속 구간 | 전월 26일 ~ 금월 25일 | 기존 확정(§8-6)과 일치 |

## 4. 부수 발견·조치

- **임금구성 키 표기 이형**(마이그 165로 정규화): 계약서 추출분 191건 중 **13건이 '기본금'**(정상 표기는 '기본급')이라
  통상임금 합산에서 누락 → 해당 직원(한도경·이태하·정다정·이원종 등) 통상시급이 0이었다. '자격수당'→'자격증수당',
  '209시간분'(근로시간 표기가 임금 항목에 섞임) 제거도 함께 처리.
- **근태 데이터 범위**: `attendance_weekly`는 2026-06-21 이후만 적재돼 있어 5월은 대조 불가.
  이 경우 산정은 신청 기준으로 하고 대장 경고에 "근태 기록이 없어 승인 신청 시간으로 산정"을 남긴다.
- **사규(신청서 본문 명시)**: 초과근무 시작 19:00(석식 후) · 야간 22:00~06:00 · 휴일근무 별도 ·
  **초과근무수당 지급 상한 월 20시간**. 다만 5월 실측은 상한 초과분(이근형 32.5h·이윤재 33h)도 전액 지급 —
  상한 미적용 관행으로 보이며, 시스템 반영 여부는 사용자 확인 필요(현재 미구현).

## 5. 구현 반영

- `lib/payroll/overtime.ts`
  - `requestedOvertime()` — 승인 신청서 집계(22시 경계로 주간/야간 분리).
  - `overtimeAmounts()` — **신청 기준 + 근태 있으면 실제 인정시간으로 캡(min)**, 근거를 `basis`로 반환
    (`requested` / `matched` / `attendance`).
  - 신청서 없이 근태만 있는 경우 **미산정**(사전 승인 없는 근무는 수당 대상 아님) + 대장 경고.
- `lib/payroll/generate.ts` — 대장 생성 시 위 결과를 반영하고 근거·차감분을 행 경고로 남긴다.
