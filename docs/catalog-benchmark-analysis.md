## 3. 구성(목차) 패턴

공통 흐름(5종 이상에서 같은 순서):

```
표지 → (브랜드 이미지 펼침) → 목차 → CEO 인사말 → 숫자로 보는 회사 → 경영철학·비전·핵심가치
→ [사업 영역 간지] 분야별 소개 → [역량 간지] 기술·연구·인증·인력 → [실적 간지] 대표 프로젝트·포트폴리오
→ 연혁 → 수상 → 네트워크(국내·해외 지도) → 뒤표지(연락처)
```

- **연혁 위치는 갈린다**: 뒤쪽 증빙 묶음(연혁·수상·네트워크)에 두는 문서(한미·대우)와 앞쪽 회사 소개 안에 두는 문서(국가철도공단·교보)가 반반.
  KESI는 설립(2016)이 짧고 인증·등록 이력이 신뢰 근거라 현행처럼 앞쪽(회사 개요 다음)에 두되, P2 목업에서 뒤쪽 배치안과 비교한다.
- **섹션 간지**는 모든 국내 문서에 있다: 단색 전면(한미), 전면 사진 + 아치형 반투명 판(대우), 섹션별 옅은 색 면 + 사진(국가철도공단), 녹색 띠 + 세로 제목(교보).
- **실적의 위치**: 본편 안에서는 '대표 프로젝트' 몇 건만 크게, 전체 목록은 뒤(한미 '프로젝트 포트폴리오') 또는 **별책**(대우 실적집). → 우리 계획(본편 대표 사례 + 부록 자동 목록)과 같은 방향.

## 5. 시각 언어 패턴

1. **단일 모티프를 끝까지 반복**: 대우 = 아치(알약) 모양 사진 틀·판·카드, 국가철도공단 = 로고 글자 선 그래픽과 큰 머리글자, 교보 = 투시 선·원형 노드.
   현행 KESI 카탈로그는 모티프가 없다(인포그래픽 스타일 4종 혼재). → P1에서 **KESI 모티프 1개**를 정한다(후보: 로고 형태에서 딴 모서리, 등고선·물결 선, 원형 노드).
2. **색은 '짙은 주색 1 + 밝은 강조 1–2 + 옅은 면'**: 7종 모두 남색·청록 계열 주색에 시안·연두 강조. KESI CI(초록·파랑)와 같은 계열이라 그대로 맞는다.
   단, 흔한 조합이므로 차별은 모티프·사진·인포그래픽으로 낸다.
3. **사진 비중이 높다**(평균 0.49–0.82, 절반 이상 쪽이 사진 50% 이상). SR(사진 비중 낮음)과 가장 크게 다른 점.
4. **사진 위 글은 판 위에만**: 대우 아치 판, AECOM 짙은 판, 국가철도공단 옅은 색 판 — SR 규칙(`overlay`)과 같다.
5. **숫자 카드에 선 아이콘**: 대우·국가철도공단 모두 아이콘 + 큰 숫자 + 짧은 라벨. 아이콘은 단색 선.
6. **지도를 정보로 쓴다**: 프로젝트 위치(한미), 지점망(교보), 사업 노선(국가철도공단), 해외 거점(대우·한미). → KESI는 **권역별 실적 지도**(A01)와 사례 위치(C11)에 쓴다.
7. **일러스트**: 대우 기술 쪽의 아이소메트릭 일러스트, ESG 쪽 평면 일러스트. 사진이 없는 주제(기술·제도)를 보여 주는 대안.
8. **세리프 제목 + 산세리프 본문**(AECOM): 환경·지속가능 주제에서 차분하고 고급스러운 인상 → 서체 세트 '격조형' 후보 근거.

## 6. 우리가 피할 것(벤치마크의 약점)

1. **작은 본문·Light 굵기**: 대우 실적집은 본문의 30%가 6pt, 회사소개도 Light 굵기 본문. 인쇄·화면 모두 판독성이 낮다 → 본문 10.5pt 이상·Light 금지 유지.
2. **글자 윤곽선 변환**(교보): 검색·복사·화면 낭독이 안 되고 파일이 무겁다 → 살아 있는 글자 유지(서체는 부분 포함).
3. **링크·북마크 0**(국내 5종 모두): 화면으로 받는 PDF인데 목차 이동이 안 된다 → 우리 차별점(북마크·목차·부록 링크).
4. **사진에 기대는 구성**: KESI는 대형사만큼 전문 촬영 사진이 없을 가능성이 높다. 표본의 구성을 그대로 따르면 빈 사진 자리나 저품질 사진이 생긴다.
   → **모든 쪽 유형에 '사진 없는 변형'을 둔다**: 인포그래픽·큰 숫자·지도·일러스트·패턴 면으로 대체. 사진 확보 계획(현장·인물 촬영 목록)을 P2에 붙인다.
5. **펼침면 전제 레이아웃**: 화면에서 펼침면 PDF는 가운데 접힘선이 사진을 가르고(한미·대우), 한 쪽씩 넘기면 반쪽만 보인다 → A4 가로 단면 결정(D1)이 맞다.
